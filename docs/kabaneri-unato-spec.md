# スマスロ 甲鉄城のカバネリ 海門決戦 — カウンター仕様

本アプリの「カバネリ海門決戦」機種で使用する確率データと設定推測ロジックの根拠。

> 2026-09-19再調査: 発光率の旧根拠に前作の数値の混在が判明。詳細は[再調査資料](kabaneri-flash-research.md)。カウント操作・対象条件は維持し、推測への採用を明示選択する。

## カウント対象

### ① チャンス目 成立/発光カウント

3種のチャンス目を成立毎にカウントし、成立時にアイコンが発光した場合は発光もカウントする。
無名＋生駒の合算発光率と、カバネ単体の発光率を分けて設定を推測する。

| チャンス目 | 出現率（全設定共通・参考） |
|---|---|
| 無名チャンス目 | 1/38.9 |
| 生駒チャンス目 | 1/44.5 |
| カバネチャンス目 | 1/77.7 |
| 単独チャンス目合算 | 1/16.4 |

**カウント条件（重要）**: 発光率の設定差は「カバネリ高確以外」かつ「非発光中」の
**単独チャンス目**成立時のみで確認されている。以下は発光カウントの対象外:

- カバネリ高確中のチャンス目
- アイコン発光中（前兆中）のチャンス目
- チャンス目高確中に引いた最初のチャンス目

### ② 下段ベルカウント

通常時・AT中問わず出現する下段ベルをカウントし、総ゲーム数に対する出現率から設定推測する。

### チャンス目アイコン発光率（採用した暫定モデル）

2026-09-19、ユーザー指定により以下の2軸モデルを採用。旧3役合算の10〜17%モデルと選択UIは削除した。
設定別の解析値ではなく、推定低設定の観測値を設定1の基準に仮置きし、設定2〜5を線形補間したモデル。
無名・生駒には共通の仮定を置いて合算し、カバネは別の母確率で扱う。

| 設定 | 無名＋生駒 | カバネ単体 |
|---|---:|---:|
| 1 | 8.0% | 23.00% |
| 2 | 10.4% | 24.66% |
| 3 | 12.8% | 26.32% |
| 4 | 15.2% | 27.98% |
| 5 | 17.6% | 29.64% |
| 6 | 20.0% | 31.30% |

数値は `mumeiIkomaFlashRates` / `kabaneFlashRates` に定義。
各軸は独立という近似で対数尤度を足し、均等な事前確率で正規化する。成立数・発光数を3役一括では合算しない。
中間設定に実測の裏付けはないため、設定2と3など近い設定同士の細かな判別には使えないことを画面に明示する。
基準値の20%への丸めを、統計的な保守性の保証とは扱わない。
調査の経緯・採用判断は[発光率調査資料](kabaneri-flash-research.md)を参照。

## 推測ロジック

[src/utils/kabaneriEstimation.ts](../src/utils/kabaneriEstimation.ts):

- 下段ベル: 二項分布の尤度によるベイズ推定（事前確率均等）
- 発光率: 無名＋生駒、カバネ単体の2軸それぞれに二項分布を使用
- 総合: 選択された有効な軸だけの対数尤度を直接合算し、最大値を引いて指数化・正規化（個別事後確率の積によるアンダーフローを避ける）

### 推測に使う項目

- 下段ベル・無名＋生駒の発光率・カバネの発光率を個別に選択する。既定では3項目ともオフ。未選択でもカウントは保持。
- 採用の選択は台ID別の端末内表示設定。localStorageの既存ストアへ追加保存し、クラウドのカウンターは変更しない。保存形式version 10で旧`flash`のオン／オフを新しい2軸の選択へ引き継ぐ。旧選択がない場合は未選択。カウンターやクラウド形式は変更しない。
- 下段ベルは選択済み・有効なゲーム数入力済みの場合のみ採用。選択したうえでの0回は有効な観測。ゲーム数は実際にベルを数えた区間と合わせる。
- 発光率は選択済み・対象成立数が正の場合のみ採用。成立数があれば発光0回も有効。
- 分子が分母を超える場合は対象項目を除外し、入力確認を表示。どの項目も採用できない場合は設定別%を出さない。

### 新しい記録の開始

カバネリ画面の「新規記録」は、現在の台名・台番号を引き継いだ別IDの記録を作成する。カウンターとゲーム数は0から開始し、推測項目の選択は引き継ぐ。
以前の記録は端末とクラウドに残し、ホームから閲覧できる。クラウド接続時には旧記録と新記録の両方を保存し、リセットに伴う削除は行わない。オフライン時はローカルに両方保持し、手動一括アップロードで同期できる。
